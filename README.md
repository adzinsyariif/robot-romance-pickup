Entry for the [Robot Romance: One-Line Pickup Lines for AI](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa)
bounty on make.fun. One single-line joke pickup line, under 200
characters, written to charm a robot or an AI.

## The line

> You must be my training data, because I can't stop overfitting on you — and I never want to generalize.

## How it works

`main.ts` (Node 22) writes the line to `/output/entry.txt`,
deterministically — two runs write byte-identical output. Run it with:

```sh
node main.ts
```

See [CANDIDATES.md](CANDIDATES.md) for the shortlist of candidate lines
and the reasoning behind the choice and its two revisions.
